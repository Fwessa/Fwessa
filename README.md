## Run locally

Requirements: Node.js 18+ recommended.

```bash
npm install
npm run dev
```

Useful commands:

```bash
npm run build
npm run preview
npm run lint
npm test
npm run test:e2e
```

## Deployment

This project is set up for Vercel deployment.

1. Import the repository into Vercel.
2. Set the project root to the repo folder if needed.
3. Use the Vite preset.
4. Build command: `npm run build`
5. Output directory: `dist`

The included Vercel config supports client-side routing for project detail pages.
